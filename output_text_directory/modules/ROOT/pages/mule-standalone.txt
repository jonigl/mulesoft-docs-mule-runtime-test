When you deploy applications on-premises, you have complete control over
the Mule instance which enables you to take advantage of certain
characteristics of the on-premises deployment model

If you want to host Mule runtime engine in your own environment, first
verify that you meet all hardware and software requirements, and then
download and install Mule.

You don’t need to install Mule in the following scenarios:

-   When you use Anypoint Studio (which contains Mule) for development
    and testing

-   When you deploy applications to CloudHub or Anypoint Runtime Fabric.

After your installation of Mule is complete, install an enterprise
license to enable all capabilities of Mule runtime engine.

Learn how to start and stop Mule runtime engine to deploy Mule
applications.

Follow the steps in Hardening your Mule Installation when you are ready
to promote your Mule applications to production.

If you want to manage your on-premises Mule instance using Runtime
Manager, register it using the Runtime Manager agent.

Learn how to choose cluster runtime instances to enhance availability,
fault tolerance, and performance characteristics.
