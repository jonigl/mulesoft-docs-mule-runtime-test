All Mule applications require deployment to a Mule runtime engine
instance to run. MuleSoft supports three different deployment targets:
CloudHub, Anypoint Runtime Fabric, and on-premises Mule instances.

When you deploy applications to CloudHub or to Anypoint Runtime Fabric,
these services automatically manage the Mule runtime engine instances
needed to run the applications.

If you deploy applications on-premises, the installation of Mule runtime
engine is required.
See On-Premises Deployment Model for more information about
characteristics specific to on-premises deployments.

In addition, different tools are available to deploy applications to
each of the deployment targets:
